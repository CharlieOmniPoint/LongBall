## What changed and how to review it

Manager fixture/training details and player Schedule filters now survive accepted saves. Administrator club saves retain a separate unsaved team draft. Temporary required-read failures keep authorised drafts disabled with explicit retry; denial closes private views even when the account itself still has access elsewhere.

Concurrent changes retain drafts without silently rebasing them. Administrator/preferences fields offer an explicit comparison; preparation forms pin their opening revision and block stale saves, with **Discard draft and close** before reopening current values. Web radios, checkboxes, tabs and pitch buttons now expose their checked/selected/pressed states alongside native accessibility state.

Archived players remain visible where saved future fixtures or training refer to them, with explicit removal before future preparation. Past attendance stays unchanged. **Open saved match preparation** reopens an existing match after later profile/template edits without trying to replace its immutable saved squad or recorded play. Foreground access checking verifies the exact selected team/season/role/player; another manager grant cannot uncover revoked Roma data.

## Run in the development workspace

```bash
cd /workspace/LongBall
source scripts/dev-env.sh
pnpm check
pnpm build:web
pnpm build:api
LONGBALL_SYNTHETIC_AUTH=1 LONGBALL_STATIC_DIRECTORY="$PWD/apps/mobile/dist-web" pnpm dev:api
```

The combined server defaults to `http://127.0.0.1:4310` on that machine. Cloud localhost is not a sharing address.
