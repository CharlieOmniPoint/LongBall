# Full feature build and evidence register

Updated 21 October 2026. The supplied canonical pack, approved visual boards, native iPhone/Android target and full F01–F28 scope remain the target. This register distinguishes implemented source, actual runtime/browser evidence, unresolved product decisions and physical-device acceptance. It is not a release-complete claim.

## Current implementation

One Expo/React Native application serves native phones and a phone-sized React Native Web review export. Shared TypeScript packages hold match, planner, reporting and access rules. Node APIs support fictional SQLite development and actual PostgreSQL; separate workers handle awards, media and generic team notifications. Local runtime and identity rehearsals use fictional data. No paid services have been provisioned. GitHub Pages hosts a static fictional-data review candidate; it is separate from the production API and identity service.

The ordinary review opens fictional Roma data. Production entry uses OIDC/PKCE and verified API memberships. Native controller/workspace requests require actual encrypted-journal diagnostics; a real-account browser controller cache cannot mount. Real browser workspace DTOs/retries remain in memory. Protected canonical and ordinary workspace outboxes retain exact request bytes/key/revision, recheck authority before replay and await durable receipts. Scoped DTOs bind API, issuer, subject, account, team, season, role, player and request generation; lock, expiry and authoritative scoped denial close private views.

Connected preparation, profile snapshots, training attendance, own responses, reports, audited historical correction, accepted-match context/archive and filtered JSON/CSV export are implemented. Rollover requires explicit manager/admin/player assignments and recent stronger administrator authentication, creates no spectator grant and preserves source documents/memberships and active matches. Scoped existing-account staff assignment/revocation and explicit own-account request controls are integrated and exercised over HTTP/browser journeys. Request submission is separate from account export/deletion fulfilment.
